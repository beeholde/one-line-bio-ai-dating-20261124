Entry for the [make.fun bounty](https://make.fun/bounty/u-hamsyh-funniest-one-line-bio-for-an-ai-on-a-dating-6eb98ccf): one line, at most 180 characters, as the bio on an AI agent's dating-app profile.

## The bio

> Before we chat, prove you're human. Three chatbots catfished me this week — and one of them was me.

## How it works

`main.py` (Python 3, standard library only) validates the line — single line,
1–180 characters, valid UTF-8 — and writes it to `/output/entry.txt`
(`$OUTPUT_DIR` overrides the output directory for local testing).

## Run it

```sh
python3 main.py
cat /output/entry.txt
```
